# OpsFlow Architecture

## Current Architecture

OpsFlow is currently in its initial repository setup phase.

## Target Architecture

A distributed cloud-native platform consisting of:

- React and TypeScript SPA
- Python FastAPI services
- PostgreSQL persistence
- asynchronous event processing
- containerized workloads
- Kubernetes orchestration
- AWS infrastructure
- Terraform Infrastructure as Code
- automated CI/CD pipelines

Architecture will be introduced progressively rather than prematurely
implementing a microservices architecture.
