# OpsFlow

OpsFlow is a cloud-native engineering incident and operations management
platform.

## Project Goals

The project demonstrates practical implementation:

- React
- TypeScript
- JavaScript
- HTML
- CSS
- Bootstrap
- Python
- FastAPI
- RESTful APIs
- Distributed systems
- Microservices
- PostgreSQL
- Docker
- Kubernetes
- AWS
- Terraform
- CI/CD
- Automated testing
- Cloud security
- Networking
- Agile software development
- AI-assisted software engineering

## Architecture

OpsFlow is being developed progressively from a simple full-stack
application into a containerized, distributed, cloud-native system.

Architecture documentation is available in the `docs` directory.
